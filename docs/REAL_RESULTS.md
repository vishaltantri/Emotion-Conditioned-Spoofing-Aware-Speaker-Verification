# Real results: EmoSpoof-TTS clones vs ESD bona fide

Provenance: **real**. Corpus: ESD English speakers 0011–0020 (bona fide, emotion
labels from the corpus folders; 17,900 trials) + EmoSpoof-TTS clones from three
neural generators — StyleTTS2, F5-TTS and CosyVoice (spoof, emotion labels from
the generator archives; 12,000 wavs each, 36,000 clones). Speaker-disjoint 4/2/4
split, **53,900 trials**: train 21,560, dev 10,780, test 21,560. Every threshold
and every model choice comes from train/dev; the test split is reported once.

Component scores, all measured on this data:

| component | model | test result | notes |
|---|---|---:|---|
| ASV | SpeechBrain ECAPA-TDNN, cosine to train-split centroid | **3.12 %** (SV-EER) | accepts 82.9 % of bona fide targets, **38.8 % of clones** — but see the per-generator split below |
| SER | wav2vec2-base-superb-er, 4-way softmax | 41.2 % acc. on bona fide, 32.8 % on clones | confidently wrong on clones: mean max prob 0.825 while 32.8 % correct |
| CM (in-domain) | log-mel CNN, train split only | **0.09 %** (SPF-EER) | optimistic by construction: sees both generators during training |
| CM (cross-generator) | log-mel CNN, StyleTTS2 held out | 1.60 % overall, **2.50 %** on the unseen generator | the CM used in the headline three-generator run |
| CM (AASIST, LA-pretrained) | official 2019-LA checkpoint | **50.8 %** | no transfer to EmoSpoof clones at all |
| CM (AASIST, LA-retrained) | AASIST trained on LA train audio | 2.11 % on held-out LA speakers, **43.8 %** on EASV test | in-domain LA detection works; the same model is at chance on EmoSpoof clones |

The ASV vulnerability is **generator-specific**, and the aggregate hides it:

| test clones | n | accepted at dev threshold | mean speaker score |
|---|---:|---:|---:|
| CosyVoice | 4,800 | 59.0 % | +0.455 |
| F5-TTS | 4,800 | 51.5 % | +0.430 |
| StyleTTS2 | 4,800 | **5.9 %** | +0.256 |

StyleTTS2 clones carry so little of the target speaker's identity that an
off-the-shelf ECAPA front-end rejects almost all of them; the same front-end
accepts more than half of the F5-TTS and CosyVoice clones. The emotion ordering
survives (angry 45.6 %, neutral 43.3 %, sad 33.2 %, happy 33.1 %), so the
"emotion changes the vulnerability" claim holds inside each generator, not just
in the aggregate.

The five manuscript figures that plot these numbers are in
[figures/](../figures/README.md), generated by
[scripts/make_figures.py](../scripts/make_figures.py) from `results/real/`; the DET
curves there reproduce each reported SASV-EER at their crossing, which is an
independent check on the metric code.

## Regime A — usable countermeasure, two-generator corpus (in-domain CM)

`results/real/run1`, `configs/real_run.yaml`, thresholds from dev only, 41,900
trials (F5-TTS + CosyVoice).

| model | SASV-EER | 95 % CI | min a-DCF | ECE | params |
|---|---:|---|---:|---:|---:|
| speaker_only | 0.3309 | 0.2605–0.3816 | 0.7294 | 0.125 | 2 |
| linear | 0.0060 | 0.0029–0.0074 | 0.0385 | 0.051 | 3 |
| emotion_additive | 0.0066 | 0.0037–0.0083 | 0.0410 | 0.051 | 9 |
| emotion_interaction | 0.0055 | 0.0031–0.0066 | 0.0359 | 0.026 | 22 |
| emotion_gated | 0.0073 | 0.0031–0.0093 | 0.0353 | 0.004 | 43 |

Paired bootstrap against `linear`: additive −0.05 pts (p=0.73), interaction
+0.05 pts (p=0.34), gated **−0.14 pts (p=0.98, i.e. slightly worse)**. No emotion
arm beats plain fusion; the countermeasure already removes almost all spoof
acceptance, so the remaining 0.6 % is ASV error and emotion carries no usable
extra signal.

## Regime B — countermeasure that does not transfer (AASIST-LA)

`results/real/run2_oodcm`, same manifest, same ASV/SER scores, CM swapped for the
out-of-domain AASIST checkpoint (SPF-EER 50.8 %, min t-DCF 0.999).

| model | SASV-EER | 95 % CI |
|---|---:|---|
| speaker_only | 0.3309 | 0.2605–0.3816 |
| linear | 0.3244 | 0.2516–0.3806 |
| emotion_additive | 0.2654 | 0.1882–0.3506 |
| emotion_interaction | 0.2661 | 0.1913–0.3470 |
| emotion_gated | 0.2610 | 0.1786–0.3483 |

Paired bootstrap vs `linear`: additive **+5.28 pts** (2.97–8.88, p<0.001),
interaction +5.19 (2.94–8.57, p<0.001), gated **+5.57** (2.86–9.85, p<0.001).

A second failing countermeasure rules out the objection that the released
checkpoint was the problem. The published AASIST architecture was retrained from
scratch on 16,000 ASVspoof 2019 LA train utterances
(`scripts/train_cm_aasist_la.py`), with 2,576 utterances from two held-out LA
speakers selecting the checkpoint. That model is a genuine LA countermeasure:
**2.11 % EER on the held-out LA speakers** (epoch 3, selected on LA dev only).
Scored once on the EASV corpus it reaches **49.4 % EER on dev and 43.8 % on
test** — chance level, exactly like the pretrained checkpoint. The negative
transfer is therefore a property of the ASVspoof-2019 supervision, not of one
particular checkpoint, and no fusion run was added for it: with a chance-level
countermeasure the ladder collapses to Regime B, which is already reported above.
An earlier attempt that selected the checkpoint on EASV dev is kept out of these
tables (`real/cm_aasist_la_ongenv_selected`); it stopped at epoch 1 with 39.8 %
dev EER, so its 40.8 % test number measured the domain gap rather than the
countermeasure.

## Regime D — three-generator corpus, cross-generator CM (the headline run)

`results/real/run4_3gen_crossgen`, 53,900 trials. The CM is trained with the
StyleTTS2 generator excluded from training *and* from dev-based early stopping,
so a third of the test spoofs come from a generator the countermeasure has never
seen. This is the complete design the research plan asked for.

| model | SASV-EER | 95 % CI | min a-DCF | min t-DCF | ECE | params |
|---|---:|---|---:|---:|---:|---:|
| speaker_only | 0.2712 | 0.2143–0.3155 | 0.5826 | 0.8216 | 0.097 | 2 |
| linear | 0.0227 | 0.0101–0.0306 | 0.0583 | 0.1962 | 0.050 | 3 |
| emotion_additive | 0.0251 | 0.0097–0.0348 | 0.0671 | 0.2013 | 0.049 | 9 |
| emotion_interaction | 0.0209 | 0.0091–0.0301 | 0.0582 | 0.1881 | 0.028 | 22 |
| emotion_gated | **0.0154** | 0.0064–0.0198 | 0.0510 | 0.1661 | 0.005 | 43 |

Paired grouped bootstrap vs `linear`: interaction **+0.20 pts** (0.03–0.62,
p=0.006), gated **+0.68 pts** (0.15–1.12, p=0.002). Comparing the proposed arm
against the simpler emotion-conditioned control, which the evaluation CLI does
not do by default (`scripts/compare_arms.py`):

| contrast | SASV-EER gain | 95 % CI | p |
|---|---:|---|---:|
| emotion_gated vs emotion_interaction | **+0.48 pts** | 0.06–0.99 | 0.998 |
| emotion_interaction vs linear | +0.20 pts | 0.03–0.62 | 1.000 |
| emotion_gated vs emotion_additive | +0.85 pts | 0.25–1.46 | 1.000 |

So with a third, unseen generator in the test set, the gated arm is the best arm
and its edge over both the interaction control and the capacity control is
significant. Where the gain comes from:

| attack | linear spoof accept | gated spoof accept |
|---|---:|---:|
| StyleTTS2 (unseen by the CM) | 1.9 % | 1.2 % |
| CosyVoice | 0.1 % | 0.0 % |
| F5-TTS | 0.0 % | 0.0 % |
| bona fide targets accepted | 93.8 % | 96.0 % |
| bona fide nontargets accepted | 2.5 % | 4.4 % |

**The gate does not use emotion.** Its learned weights are almost identical
across all five emotion conditions (speaker weight 4.02–4.05, CM weight
9.69–9.73 — a spread under 0.5 %), so the model is not conditioning its decision
on emotion; it is a better-fitting, better-calibrated decision function that
happens to beat the interaction model on this split. The same collapse appears in
every regime: in Regime A the five per-emotion gate weights agree to three
decimals. That is the honest reading of the positive result above — the paper's
mechanism claim is still unsupported by this data, even though its *predictive*
arm now wins.

## The catch: why the Regime B gain is not (only) emotion conditioning

The SER front-end is confidently wrong on clones: 32.8 % accuracy — barely above
the 25 % chance level — with a mean maximum probability of 0.825, against 41.2 %
and 0.796 on bona fide speech. The emotion probability vector therefore carries a
**spoof cue**: "confidently wrong emotion" correlates with being synthetic. That
is enough to explain a 5-point SASV-EER gain from emotion features without any
genuine emotion-conditioned speaker/countermeasure modelling. It is a labelling
hazard for any paper claim built on a weak CM. The confirmatory test for a future
pass: retrain the fusion arms with the emotion features replaced by one explicit
"SER confidence" scalar and see whether the Regime B gain survives. Given the
gate-weight collapse in Regime D, the same ablation would settle whether the
gated arm's advantage is anything more than capacity and calibration.

**That ablation has now been run** — see the next section. Both of its questions
are answered, one in each direction.

## SER-confidence ablation: the Regime B gain splits, the Regime D win does not need emotion

`configs/ablation_ser_confidence.yaml` replaces the four-dimensional emotion
probability vector with a **single scalar** — the SER's maximum predicted
probability per trial — and refits every arm (`training.emotion_features:
confidence_only`). Runs: `results/real/run2b_serconf` (Regime B) and
`results/real/run4b_serconf` (Regime D); same manifest, ASV and CM scores as the
parent runs, dev-only thresholds, 1,000-resample paired grouped bootstrap.
Sanity check: the emotion-free arms reproduce the parent runs exactly (Regime B
speaker-only 0.3309 / linear 0.3244; Regime D 0.2712 / 0.0227), so only the
feature construction changed.

### Regime B — failing AASIST-LA countermeasure (test n = 16,760)

| model | confidence-only SASV-EER | gain vs linear | full-vector SASV-EER | gain vs linear |
|---|---:|---|---:|---:|
| linear | 0.3244 | — | 0.3244 | — |
| emotion_additive | 0.3026 | +1.60 pts (CI 0.70–2.74, p<0.001) | 0.2654 | +5.28 pts |
| emotion_interaction | 0.3036 | +1.60 pts (CI 0.58–2.78, p<0.001) | 0.2661 | +5.19 pts |
| emotion_gated | 0.3089 | +1.18 pts (CI −0.83–3.29, p=0.20) | 0.2610 | +5.57 pts |

Cross-run paired contrast, confidence scalar vs full vector (same arm, same
test split): additive **−3.68 pts** (CI −7.68…−0.78) and interaction **−3.59 pts**
(CI −7.34…−0.81), both favouring the full vector significantly.

Reading: the single scalar recovers about **a third** of the +5.4-point gain
(significantly), so part of the Regime B gain is indeed the spoof cue. But the
full vector is significantly better than the scalar, so the remaining two thirds
come from the *per-class* structure of the SER output. Given that the SER is only
32.8 % accurate on clones, the honest description of that residual is
**per-class out-of-domain behaviour**, not demonstrated emotion semantics: the
four probabilities together encode "which wrong label the model confidently
chose", which is more informative than how confident it was, but is still a
property of a model operating out of distribution. Regime B therefore cannot be
cited as evidence for emotion-aware fusion even in the reframed form.

### Regime D — three generators, cross-generator countermeasure (test n = 21,560)

| model | confidence-only SASV-EER | gain vs linear | full-vector SASV-EER | gain vs linear |
|---|---:|---|---:|---:|
| linear | 0.0227 | — | 0.0227 | — |
| emotion_additive | 0.0240 | −0.07 pts (CI −0.27…0.11, p=0.78) | 0.0251 | −0.24 pts |
| emotion_interaction | 0.0232 | +0.01 pts (CI −0.10…0.20, p=0.49) | 0.0209 | +0.20 pts |
| emotion_gated | **0.0149** | **+0.70 pts** (CI 0.14–1.23, p=0.002) | 0.0154 | +0.68 pts |

Cross-run paired contrast for the headline arm: confidence-only gated vs
full-vector gated **+0.02 pts** (CI −0.04…+0.09, p=0.76) — statistically
indistinguishable; the scalar version is in fact marginally better. The
interaction arm, by contrast, does need the full vector (confidence-only is
−0.19 pts worse, CI −0.59…+0.03, p=0.046).

**This settles the mechanism question.** The gated arm's entire Regime D edge is
reproduced — to the third decimal — with a single confidence scalar. The gate
cannot be doing emotion conditioning here by construction: its input is now
one-dimensional. The +0.7-point win over linear fusion is a capacity and
calibration effect on one spoof-correlated feature, exactly what the flat
gate weights suggested. Any paper wording that credits the gated arm's win to
emotion is now contradicted by two independent measurements (flat per-emotion
weights, and scalar-only reproduction).

## Held-out-emotion folds: nothing is memorised, because nothing is used

The objection this closes is "emotion-aware, but was it ever tested on an emotion
it had not seen?". Two folds were run: `angry` and `neutral`. In each, the
emotion is removed from **both** stages that could learn it — the countermeasure
training and the fusion fit (train + dev, so the threshold and any per-emotion
weight come only from the other four emotions). The test split is untouched, so
the held-out trials are scored by a pipeline that never saw that emotion.

The exclusion is real: train 21,560 → 16,520 trials, dev 10,780 → 8,260; the
countermeasure's own metrics confirm it, at 0.03 % CM-EER on the excluded
emotion's test trials (overall 0.08 %) for both folds — clones are spectrally
unnatural whatever emotion they carry.

Each held-out CM is paired with two fusion fits: **fold off** (all five emotions
in the fit, the parent behaviour) and **fold on** (the emotion excluded). Comparing
the pair isolates what the emotion identity was worth to the fusion stage.

Whole test split, SASV-EER (n = 21,560):

| held out | fit | linear | additive | interaction | gated |
|---|---|---:|---:|---:|---:|
| `angry` | fold off | 0.51 % | 0.59 % | 0.47 % | 0.61 % |
| `angry` | fold on | 0.52 % | 0.61 % | 0.52 % | 0.61 % |
| `neutral` | fold off | 0.36 % | 0.45 % | 0.38 % | 0.53 % |
| `neutral` | fold on | 0.36 % | 0.46 % | 0.34 % | 0.47 % |

On the held-out emotion's own test trials (n = 5,040), fold-on vs fold-off,
paired grouped bootstrap over claimed speakers:

| held out | arm | fold off | fold on | paired gain | 95 % CI | p(not worse) |
|---|---|---:|---:|---:|---|---:|
| `angry` | linear | 0.43 % | 0.43 % | −0.006 pts | −0.071 … +0.055 | 0.81 |
| `angry` | interaction | 0.36 % | 0.36 % | −0.008 pts | −0.077 … +0.027 | 0.72 |
| `angry` | gated | 0.55 % | 0.57 % | −0.008 pts | −0.055 … +0.000 | 0.77 |
| `neutral` | linear | 0.16 % | 0.16 % | +0.000 pts | −0.027 … +0.027 | 0.86 |
| `neutral` | interaction | 0.21 % | 0.21 % | +0.000 pts | +0.000 … +0.000 | 1.00 |
| `neutral` | gated | 0.29 % | 0.27 % | +0.029 pts | +0.000 … +0.126 | 1.00 |

**The pipeline transfers to unseen emotions with no measurable loss** — the
largest difference anywhere is 0.03 points, and every interval at that scale
contains zero. But the reason is not that the arms generalise *well*; it is that
they had almost nothing emotion-specific to lose. That is the third independent
signal pointing the same way: the gate weights are flat across emotions, a single
SER-confidence scalar reproduces the Regime D edge, and deleting an entire
emotion from the fit changes nothing. An arm that genuinely conditioned on emotion
would show a fold cost; these do not.

Caveat: the held-out fold is measured against a countermeasure that transfers to
the unseen emotion almost perfectly (0.03 %). The CM axis is therefore not the one
under stress here — this experiment tests the fusion stage. On a failing CM
(Regime B) the fold could bite much harder, and that has not been run.

## Seed stability of the arm ordering

The fits were repeated on four seeds (7, 11, 23, 37) in the two decisive regimes,
to check that the ordering is a property of the data rather than of one
initialisation. SASV-EER (%) on the test split:

| regime | seed | linear | additive | interaction | gated |
|---|---|---:|---:|---:|---:|
| A (in-domain CM) | 7 | 0.60 | 0.66 | **0.55** | 0.73 |
| A | 11 | 0.60 | 0.66 | **0.55** | 0.79 |
| A | 23 | 0.60 | 0.66 | **0.55** | 0.77 |
| A | 37 | 0.60 | 0.66 | **0.55** | 0.77 |
| D (StyleTTS2 held out) | 7 | 2.27 | 2.51 | 2.09 | **1.54** |
| D | 11 | 2.27 | 2.51 | 2.09 | **1.47** |
| D | 23 | 2.27 | 2.51 | 2.09 | **1.40** |
| D | 37 | 2.27 | 2.51 | 2.09 | **1.49** |

The conclusion is the same in every seed: the gated arm is the best model in
regime D and worse than plain fusion in regime A, and the interaction control is
the best emotion arm wherever the countermeasure works. The gated arm's spread in
regime D is 1.40–1.54 % (mean 1.48, sd 0.06), so its edge over linear fusion is
0.73–0.87 points across seeds.

One caveat about what this shows: only the gated arm moves. The other three arms are
fitted by convex procedures that reach the same optimum from any seed, so their
constancy is a property of the fitter, not evidence of robustness. The seed test is
informative only for the non-convex arm — which happens to be the one whose claim is
under test.

## What these results do and do not establish

Established (measured, real audio, dev-only thresholds, test reported once):

* an off-the-shelf ECAPA ASV accepts **38.8 %** of neural emotional clones as the
  cloned speaker, and the rate is generator-dependent (CosyVoice 59.0 %, F5-TTS
  51.5 %, StyleTTS2 5.9 %) and emotion-dependent inside each generator;
* standard spoofing-aware fusion removes nearly all of that vulnerability when
  the countermeasure works (33.1 % → 0.6 % SASV-EER in Regime A);
* the LA-pretrained AASIST checkpoint does not transfer to EmoSpoof-TTS clones
  (EER 50.8 %), and neither does an AASIST retrained in-domain on LA audio
  (2.11 % on held-out LA speakers, 43.8 % on EASV test), while a small log-mel
  CNN trained on two generators detects a third at **2.50 %** EER —
  generator-adjacent training data matters far more than the ASVspoof lineage;
* on the complete three-generator design the proposed gated arm is the best model
  (**1.54 %** SASV-EER vs 2.27 % linear), and its edge over the interaction
  control (+0.48 pts, CI 0.06–0.99) and the capacity control (+0.85 pts) is
  significant;
* the gated arm's learned gate weights are flat across emotions, so that edge
  cannot be attributed to emotion-conditioned gating;
* with a failing CM, emotion features cut SASV-EER by ~5.5 points; the
  confidence-scalar ablation splits the gain — a single max-probability scalar
  recovers +1.6 points (significant) and the full vector is significantly better
  than the scalar (−3.7 pts), so roughly a third is a spoof cue and the rest is
  per-class out-of-domain SER behaviour, not demonstrated emotion semantics;
* the gated arm's Regime D edge is **fully reproduced by the confidence scalar
  alone** (1.49 % vs 1.54 %, indistinguishable, p=0.76), so it is a capacity and
  calibration effect, not emotion conditioning — two independent measurements
  now rule the mechanism out;
* excluding an entire emotion from both countermeasure training and fusion fitting
  costs **no measurable accuracy on that emotion** (≤0.03 points on 5,040 held-out
  trials, every CI spanning zero, two folds), so the pipeline is not relying on
  memorised emotion identities — and it loses nothing because it was hardly using
  them.

Not established:

* that emotion *conditioning* — as opposed to extra capacity and a better
  calibration of the same two signals — produces the Regime D gain; the gate
  weights say it does not;
* any *emotion-conditioned* behaviour that survives a held-out emotion: the fold
  is free precisely because the emotion features contribute little beyond a
  spoof-correlated scalar;
* a cross-generator *benefit* from the gated arm in the two-generator corpus
  (Regime C: +0.27 pts, CI includes zero) — the positive result appears only once
  the third generator is present, and the two settings have to be reported side
  by side rather than merged;
* held-out-emotion behaviour against a failing countermeasure (Regime B); only
  the working-CM regime was folded.

  .venv/bin/python scripts/combine_scores.py --speaker $D/real/scores_asv_merged.csv \
      --cm $D/real/cm_holdout_emo_$EMO/scores_cm_indomain.csv \
      --emotion $D/real/scores_ser_merged.csv --out $D/real/scores_combined_emo_$EMO.csv
  # fold off: fusion sees all five emotions (what the emotion identity is worth)
  .venv/bin/python -m easv.cli evaluate --manifest results/e2e/merged_manifest.csv \
      --scores $D/real/scores_combined_emo_$EMO.csv --config configs/real_run.yaml \
      --out results/real/run5_holdout_${EMO}_off
  # fold on: the emotion is also excluded from fusion train/dev
  .venv/bin/python -m easv.cli evaluate --manifest results/e2e/merged_manifest.csv \
      --scores $D/real/scores_combined_emo_$EMO.csv --config configs/real_run.yaml \
      --set folds.holdout_emotion=$EMO --out results/real/run5_holdout_${EMO}_on
  # paired contrast on the held-out emotion's own test trials
  .venv/bin/python scripts/compare_arms.py --results results/real/run5_holdout_${EMO}_on \
      --results-b results/real/run5_holdout_${EMO}_off \
      --manifest results/e2e/merged_manifest.csv \
      --a emotion_gated --b emotion_gated --emotion $EMO
done

# ASVspoof 2019 LA: build the manifest, then retrain AASIST in-domain
.venv/bin/python scripts/build_manifests.py asvspoof \
    --la-root $D/asvspoof2019LA --out results/e2e/m_asvspoof_la.csv
.venv/bin/python scripts/train_cm_aasist_la.py --la-manifest results/e2e/m_asvspoof_la.csv \
    --easv-manifest results/e2e/merged_manifest.csv --aasist-root $D/aasist \
    --out-dir $D/real/cm_aasist_la --device cuda --epochs 3 --max-train 16000 \
    --batch-size 12 --amp bf16
