# Publication action plan — workshop-first (updated 2026-10-23)

**Decision recorded:** the submission deadline is in weeks and the ESD licence reply
would take months, so the work is planned for a **workshop/conference submission**
(ASVspoof workshop, ICASSP/Interspeech, Odyssey), not a journal. The licence is
demoted from blocker to footnote:

* A course research project is inside ESD's stated terms ("free to use only for
  research purpose", [official download page](https://hltsingapore.github.io/ESD/download.html)).
* The EmoSpoof-TTS clones are **CC BY 4.0** and contain no ESD audio
  ([Zenodo 15557842](https://zenodo.org/records/15557842)) — the spoof side needs
  no permission at all.
* Action: send [docs/ESD_LICENCE_EMAIL.md](ESD_LICENCE_EMAIL.md) anyway (10 minutes),
  cite it as "research use per ESD terms; licence requested" in the data statement.
  Never upload audio; scores and manifests only. The signed licence unlocks a
  journal submission later, not this one.

**What the licence was never going to fix:** the mechanism claim. The learned gate
is flat across emotions and the gated arm loses to plain fusion on the
two-generator corpus, so "emotion-conditioned gating improves SASV" is refuted by
our own data. The novelty that survives has nothing to do with the licence:

1. ASV vulnerability to emotional neural clones is **generator-specific**
   (5.9 % / 51.5 % / 59.0 % acceptance for StyleTTS2 / F5-TTS / CosyVoice, hidden
   in the pooled 38.8 %);
2. **countermeasure transfer is governed by generator adjacency, not ASVspoof
   lineage** (AASIST-LA 50.8 % EER; LA-retrained AASIST 43.8 % on EASV while
   scoring 2.11 % on held-out LA speakers; small adjacent-generator CNN 2.50 % on
   an unseen generator);
3. the **flat-gate finding** plus the **SER spoof-cue hazard**: with a failing
   countermeasure, emotion features gain ~5.5 SASV-EER points while the SER is
   confidently wrong on clones — the likely mechanism is an implicit spoof cue,
   not emotion conditioning.

Defensible contribution sentence: *a systematic cross-generator SASV evaluation on
emotional neural clones, with a five-arm fusion ladder and mechanism introspection
showing why emotion-conditioned fusion does not deliver what it promises.* GEM
(Interspeech 2025, the closest work) is anti-spoofing only: no speaker branch, no
fusion ladder, no gate introspection. No "first"/"novel" wording until the novelty
gate in [docs/NOVELTY_MATRIX.md](NOVELTY_MATRIX.md) closes.

  1–4: they add surface, not evidence.
